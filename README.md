# Shooter Game

A single-page browser shooter game prototype.

## Play

Open `index.html` in a browser.

## Controls

- `WASD` or arrow keys: move
- Mouse: look
- Mouse click or `F`: shoot
- `Space`: jump
- `R`: reload
- `1`-`9`: use inventory slots

## Files

- `index.html` - page structure
- `styles.css` - game UI styling
- `game.js` - gameplay, rendering, bots, traps, inventory, shop, and combat effects
